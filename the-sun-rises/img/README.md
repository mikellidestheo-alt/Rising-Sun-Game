# Images for The Sun Rises

Drop files here with exactly these names. Anything missing is shown as an inked placeholder with initials, so the game never breaks.

- Portraits: 5:6 ratio works best (they are cropped to 400 × 480). Keep each under about 150 KB.
- Backgrounds: 16:9 (shown at 1280 × 720).
- `tools/prep_img.py` resizes and compresses: `python3 tools/prep_img.py portrait in.jpg img/ito.jpg` or `python3 tools/prep_img.py bg in.jpg img/bg_tsushima.jpg`.

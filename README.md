# Rising-Sun-Game

## The Sun Rises
A decision-making history game for Cambridge International AS Level History (9489), Topic 1: how and why Japan emerged as a world power, 1853–1919. Companion to *Shadows over Geneva*.

- Play: https://mikellidestheo-alt.github.io/Rising-Sun-Game/the-sun-rises/
- Folder: `the-sun-rises/` (`index.html` with all CSS and JS inline, plus `img/`)
- Edit the text: open `the-sun-rises/index.html` and find the block headed `THE SUN RISES — ALL GAME TEXT LIVES HERE`.
- Portraits and backgrounds: see `the-sun-rises/img/README.md`.
- `the-sun-rises/tools/` holds the scripts used to build the map data and prepare images; the game does not need them.
